# CSP-CODE
This is my portfoilio of a couple of projects that display my work during the year across AP Computer Science Principals. Each project shows my different skills that I have learned and how they can apply to various situations.
Below is a quick description of the included projects:
Chicago Traffic Volume Filter:
Description- A Python program that analyzes traffic volume data across major Chicago streets and filters roads based on a user-defined traffic threshold. Useful for basic traffic pattern exploration and conditional filtering practice. 
Key Elements: 
• Lists and array management 
• Conditional filtering with loops 
• User-defined traffic thresholds 
• Real-world city traffic dataset 
• Beginner-friendly data analysis concept
U.S. National Parks Recommendation System 
Description: 
An interactive travel recommendation program that helps users discover U.S. National Parks based on region, park features, popularity, and park size. Includes park information lookup and randomized travel suggestions using dataset-driven logic. 
Key Elements: 
• Interactive command-line menu 
• CSV dataset integration with Pandas 
• Randomized recommendations 
• Search and filtering functions 
• Regional categorization system 
• Web browser integration for park images 
• Nested conditionals and loops 
• Tourism and travel planning application 
 Hawaii Island Adventure Recommender
 Description: 
 A simple interactive Python program that recommends Hawaiian islands to users based on travel preferences such as popularity and activity type.
 Key Elements: 
 • Nested conditional statements
 • User input handling 
 • Travel recommendation logic

 • Simple interactive experience hacker
  Cybersecurity Incident Data Analyzer
  Description: 
  A Python-based cybersecurity data analysis tool that processes breach and incident records from a CSV dataset. The program identifies incidents by keyword and analyzes large-scale data events.
  Key Elements: 
  • CSV data processing with Pandas 
  • Keyword-based incident searching 
  • Data filtering and analysis 
  • Cybersecurity-themed dataset exploration 
  • Looping and conditional logic 
  • Basic reporting and metrics generation
   Python Slot Machine Simulator 
   Description: 
   An interactive casino-style slot machine game built in Python that allows users to deposit credits, spin randomized slot symbols, and win rewards based on matching outcomes. Includes both a playable game mode and a large-scale simulation mode to analyze casino profit behavior. 
   Key Elements: 
   • Interactive command-line gameplay
   • Randomized slot machine outcomes
   • Credit and balance tracking system
   • Jackpot and reward payout logic 
   • Weighted probability simulation
   • Casino profit/loss analysis
   • Loops and conditional statements 
   • Beginner-friendly game development concepts
